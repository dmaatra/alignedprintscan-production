# APS Manual Screenshot Assets

This directory contains the 19 controlled instructional visuals referenced by `docs/manual-source/SCREENSHOT_MANIFEST.md` and the canonical Operations Manual. SS-020, SS-030, and SS-090 are controlled synthetic production captures. The other images are visibly labeled local APS Manual documentation fixtures grounded in maintained workflows; they do not assert that consequential production activity occurred.

All visuals omit browser chrome and sensitive URLs and remain free of permanent editorial markup. Credentials, portal tokens, legitimate customer data, Brandi Turnbo data, real payment/refund details, identity/KBA information, legitimate documents, provider identifiers, and secrets are prohibited. Editorial callouts are documented in the manifest and Manual v2.3.
