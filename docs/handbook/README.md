# APS Operator Handbook 3.0

This directory contains the publication-quality Operator Edition and its reproducible builder.

- `Aligned_Print_Scan_Operator_Handbook_v3.0.docx` is the editable Word edition.
- `Aligned_Print_Scan_Operator_Handbook_v3.0.pdf` is the matching production PDF.
- `build_operator_handbook.py` builds both editions from current repository policy pages, workflow documentation, maintained template specifications, the admin operator-reference catalog, and the 19 approved manual visuals.

The handbook uses current production behavior as its technical baseline. Texas notarial content must be revalidated against the Texas Secretary of State educational materials, Texas Government Code Chapter 406, and applicable Texas Administrative Code rules whenever substantive notarial wording changes.

The Word document deliberately preserves real heading styles, bookmarks, PAGEREF fields, internal links, editable text/tables, alt text, repeated table headers, non-splitting rows, section breaks, and landscape matrices. Regenerate and visually inspect every page after any source or layout change.
