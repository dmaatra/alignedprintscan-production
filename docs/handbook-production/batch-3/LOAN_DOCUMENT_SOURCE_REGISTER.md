# Loan Document Source Register

## Authoritative external sources

1. Consumer Financial Protection Bureau — Closing Disclosure and official closing-document consumer guidance.
2. Fannie Mae/Freddie Mac Uniform Instruments — current notes, riders/addenda, security instruments, and special-purpose documents.
3. HUD Single Family Housing Model Documents — current HECM/reverse-mortgage notes, mortgages, agreements, disclosures, and borrower/non-borrowing-spouse certifications.
4. Texas Secretary of State — traditional and online notary educational information; Texas Government Code Chapter 406; applicable Texas Administrative Code.

## Qualification rule

The catalog describes common operational purpose and presentation. It does not determine whether a document belongs in a package, whether it is legally sufficient, or whether it must be notarized.

**COMMONLY NOTARIZED DOES NOT MEAN ALWAYS NOTARIZE.** Actual authority comes from the document in front of the operator, its actual certificate, applicable law, and authorized assignment instructions.

Commercial/custom instruments, lender-specific affidavits, title/escrow forms, tax forms, insurance documents, and nonstandard modification documents vary materially. Their actual package and ordering-party instructions remain authoritative. These entries are source-qualified rather than generalized into legal conclusions.
